# 值得买设计规范 AI 知识库

这是「卡片查找器」之后的独立长期项目。它保存经过整理和确认的设计知识，供产品、设计、研发、测试和 AI 共用。

当前已经迁入第一批可复用成果：261 份卡片档案、419 个原始页面 Frame、486 条页面关系、卡片预览图、页面分类规则，以及可安装的卡片查询 Skill。现有内容是项目起点，其中不少业务语义仍需设计或研发确认。

当前应用构建：0.3.0-mvp.1；知识版本仍为 2026.09.11-r1。已补六层精炼知识、重点卡片评审档案、来源和待确认清单；新增档案尚未人工确认。

## 知识助手 MVP

新增全量卡片库、双卡对照、规范档案、检索、资料导出、本机历史、反馈和 Codex 交接。默认由每个人自己的 Codex 使用项目级 Skill 完成 AI 归纳与评审，网页不要求模型密钥。

运行 `npm ci`、`npm run build:app`、`npm run build:installer` 后用 `npm start` 启动，默认地址 `http://127.0.0.1:4317`，需要 Node.js 22.13 或更新的 22.x 版本。当前交付与部署状态统一见 [MVP 交付状态](docs/MVP交付状态.md)。

## 最终会形成什么

- 一套权威设计档案：设计原则、基础视觉、组件、页面模式、交互状态、研发与测试映射。
- 一套适合 AI 阅读的入口：`llms.txt`、`design.md`、分主题 Markdown 和结构化数据。
- 一套可安装的 Skill：AI 在回答编号、选型、页面关系或生成设计前，按统一规则查询资料。
- 一个团队查询网站：可视化搜索、卡片与页面双向查询、对比、审核和版本说明。
- 一套维护机制：认领、确认、变更、废弃、发布和质量检查。

## 文件分区

| 目录 | 内容 | 谁来维护 |
| --- | --- | --- |
| `knowledge/` | 经过人工打磨、准备成为正式规范的知识 | 各领域设计负责人 |
| `source/card-finder/` | 从卡片查找器同步来的原始证据与生成档案 | 管理员和脚本 |
| `templates/` | 组件、页面、基础规范的填写模板 | 设计系统负责人 |
| `governance/` | 认领、确认、变更和发布规则 | 项目负责人 |
| `packages/` | 可安装给 AI 使用的 Skill | AI/工具维护者 |
| `docs/reference/` | 早期方案和参考资料 | 只作参考 |

`source/` 是导入区，重新同步时可以覆盖；设计师补充的正式内容应写进 `knowledge/`，避免被覆盖。

## 常用命令

```bash
npm run validate
npm run sync:cards
npm run build
npm run query -- search 字号
npm test
```

`validate` 检查编号、预览、元数据、引用和构建一致性；`sync:cards` 从旁边的「卡片查找器」重新导入卡片资料，之后需重新构建。完整命令和验证边界见 [试用指南](docs/试用指南.md) 与 [验证记录](docs/验证记录.md)。
