# 初版验证记录

版本：2026.09.11-r1。验证日期：2026-09-11。

## 可重复检查

- npm run build：从源文档、来源/问题清单和卡片快照构建查询页面与索引。
- npm run validate：检查编号唯一、源文件/预览存在、元数据、来源/问题引用、Markdown 本地链接、源数据与 Skill 快照一致、构建产物未过期。
- npm test：验证精确编号和多关键词检索、缺失记录退出、证据统计分离、未命名状态保留；在隔离 DOM 中检查页面搜索、过滤、空状态、对比、来源/问题跳转、报告和 CSS 解析。

## 验证边界

DOM 测试不启动浏览器、不加载外部资源，不能证明实际像素布局、图片视觉质量或打印分页已经验收。浏览器工具的 URL 安全策略拒绝打开本地 HTML，因此本轮没有浏览器桌面/移动截图验收，也没有通过其他浏览器方式绕过这一限制。

PC 官网本轮未完成视觉与交互实测；来源登记已注明公开文本采集限制。产品代码、接口和运行状态未接入，本项目测试不等于值得买业务 UI 回归测试。

实际检查是否通过以本次命令输出为准；修改后需重跑检查。没有部署外网或更改 Figma 源文件。
