# 动效与连续性

## 目的
让进入、退出与状态变化可感知，保留空间关系和操作反馈。

## 来源参数（待确认）
[缓动和持续时间对照表 919:263](https://www.figma.com/design/VNy5gakyf4IyApJayH1mnD/?node-id=919-263)：
| 缓动类别 | 时长 | 来源用途 |
| --- | --- | --- |
| 强调 | 500ms | 在屏幕上开始和结束 |
| 强调减速 | 400ms | 进入屏幕 |
| 强调加速 | 200ms | 退出屏幕 |
| 标准 | 300ms | 在屏幕上开始和结束 |
| 标准减速 | 250ms | 进入屏幕 |
| 标准加速 | 200ms | 退出屏幕 |
未取得曲线控制点，不能用任意 CSS easing 冒充精确映射。

## 来源原则
[910:41](https://www.figma.com/design/VNy5gakyf4IyApJayH1mnD/?node-id=910-41)建议保持方向一致、避免突兀跳切、保持加载内容位置稳定，并遵循简化动画设置。

## 初版验收建议
快速连续操作不应累计排队；加载时预留结构空间；开启减少动态效果后保留结果反馈。退出动作能否更短须结合组件，不能把所有反馈强制延迟到动画结束。

## 不适用情况
品牌动画、视频内容、复杂演示不能直接套用该表。当前不构成全端统一时长批准。
