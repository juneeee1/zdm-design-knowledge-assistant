# 价格与内容表达

## 目的
在紧凑内容中保留影响消费判断的信息。以下是基于公开文本和卡片备注形成的工作建议。

## 观察依据
官网公开条目出现价格及用券、多件等条件；23001 的来源备注描述广告配置时的标识。具体卡片事实由对应精炼档案和原始记录维护，不在这里扩写为全局硬规则。

## 建议表达
| 情况 | 建议 | 不应做 |
| --- | --- | --- |
| 有优惠条件 | 价格与条件能被一起理解 | 只留下低价数字 |
| 单价与总价并存 | 标清单位及数量口径 | 不注明是单件还是合计 |
| 返积分或权益 | 区分实际支付与返后口径 | 把不同口径合并为无条件价格 |
| 价格缺失 | 使用经评审的缺失策略 | 填 0 元或虚构价格 |
| 商业内容 | 按已确认配置显示身份 | 因空间不足自行移除标识 |
| 长标题 | 依组件约束截断，保留识别信息 | 自造统一行数或吞掉条件 |

## 合成示例
“到手 49 元，需买 2 件并用券”是说明信息结构的虚构样例，不是线上价格；单件/整单口径还应在业务定义中明确。不能作为生产数据使用。

## 交互与验收建议
用长标题、多条件、单位价格、缺价、过期优惠组成样例集。检查窄容器和大字号下价格与条件是否仍可关联，广告标签与可点击区域是否冲突。

## 确认记录
暂无人工确认；字段定义和最终展示优先级待业务确认。
