# 知识库地图

正式知识按六层组织：

1. `01-设计原则`：回答为什么这样设计。
2. `02-基础规范`：颜色、字体、间距、圆角、阴影、图标、图片和多端规则。
3. `03-组件规范`：卡片、按钮、标签、价格、导航、筛选、弹窗等可复用零件。
4. `04-页面模式`：组件如何组合成首页、搜索、好价、详情和发布流程。
5. `05-交互与内容`：操作反馈、异常状态、动效和文案规则。
6. `06-研发与测试映射`：设计编号、研发组件、接口字段、验收和回归范围。

当前先建设第三层的卡片模块。导入资料位于 `../source/card-finder/`；人工确认后的精炼档案再放进本目录对应位置。
