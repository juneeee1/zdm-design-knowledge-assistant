# Token 覆盖与未知值

## 目的
为后续设计变量和代码样式建立可审计的入口，不将少量样例包装为完整设计系统。

## 标准值与允许范围
| 语义 | 当前值 | 依据 | 可用范围 |
| --- | --- | --- | --- |
| 文字色/链接色 | #447dbd | 811:6118 的变量读取结果 | 仅证实该节点关联定义，待确认 |
| 品牌主色、价格色、危险色 | 未知 | 未取得完整变量库 | 不自动赋值 |
| 间距、栅格、断点 | 未知 | 缺少现行规则 | 不从官网猜 |
| 圆角、阴影 | 未知 | 缺少现行规则 | 不提升组件局部数值为全局 Token |
| 字体文件与回退链 | 未知 | 缺少资产/代码 | 不把卡片备注字体推广到全部页面 |

## 正确与错误示例
正确：原型为未知值采用局部临时样式，并在交付说明标记待替换。
错误：把知识库查询页面自身配色视为 DaMo；把单卡片“间距由3改6”升级为全局间距阶梯。

## 适用范围
本版 Token 为证据清单，不直接导出生产 CSS 变量包。颜色值不隐含深色模式、禁用态或用途扩展。

## 研发变量与验收建议
每个候选 Token 后续补 Figma key、集合、模式、别名关系、代码变量、使用范围、废弃替代及确认记录。导出时仅选择目标端与版本已确认的记录。
